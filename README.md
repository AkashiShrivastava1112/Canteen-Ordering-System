# Canteen / Food Ordering System

## 1. Introduction

Canteen / Food Ordering System is a Python based application created to ease the process of choosing food items and calculating the final amount of the selected food items.

The application shows the menu containing various food items along with their prices.
It allows the user to select multiple dishes, choose quantity, calculate total amount, apply discount and shows the final bill amount.
The application is built using streamlit framework providing interactive web interface.
---
## 2. Features
- Menu with food items and price
- Multiple food items selection
- Quantity selection
- Total amount calculation
- Discount applicaton (10%)
- Final amount calculation
- Empty order validation
- Order summary
- Final message
